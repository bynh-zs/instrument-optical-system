BAM 物理模型与十因素数值仿真 · 结果摘要
================================================================
建模基准    n1=1.000  n2=1.333  θB=53.1232°  λ=632.8 nm
实测修正    n2(632.8nm,20°C)=1.332106  θB=53.1048°  Δ=0.0185°
            dn/dT=-9.200e-05/°C  dθB/dT=-0.0019°/°C
裸界面      R_p(θB)=0.000e+00（浮点精确零）   R_s(θB)=0.078271
独立校核    Fresnel 解析式 vs 特征矩阵(d=0)：0–85°、1001 点、p/s 两偏振
            最大绝对偏差 DEV_MAX=2.83e-15（双精度机器精度）
            k = R_film/d0^2 = 6.131e-07 nm^-2（不是 2.45e-6）
            解析灵敏度 2k·d0 = 2.452e-06 /nm，数值差分 2.452e-06 /nm，
            相对差 2.14e-04
膜区基准    nf=1.50  d0=2.0 nm  R_film=2.452203e-06
灵敏度      dR/dd = 2.451678e-06 /nm
最小反射角  有膜(d=2 nm)时 R_p 极小值出现在 θB+0.0065°（膜层改变有效布儒斯特条件）；
            因此 |Δθ|<0.0065° 时 R 可能略降，本扫描取 Δθ=+0.05° 以落在单调上升区。
            这也说明固定角度法（Hönig & Möbius 1991）中成膜引起反射率上升是稳健的。
基准对比度  C0 = (R_film − R_bg)/R_bg = 1.8  (R_bg 含 GL10-A 的 s 泄漏 R_s/1e5)

分辨率链    Rayleigh δ=0.61λ/NA = 1.3786 µm (⊥入射面)
            斜视投影 1/cosθB = 1.6664
            → 沿入射面 δ = 2.2973 µm
            像元物面 = 5.5/10 = 0.550 µm < Nyquist 0.6893 µm  ✓ 满足
            视场 = 1.126 mm，斜视沿入射面 = 1.876 mm

对焦        液面与光轴夹角 = 90°−θB = 36.8768°（液面与焦面夹角 = θB）；景深按全深计
            沿液面距中心 x 处的轴向离焦 = x·cos(TILT) = x·sinθB
            → 清晰带全宽 W = DOF/sinθB = DOF/cos36.88° = 4.38 µm
              （半宽 ≈ 2.19 µm；W = DOF/cos36.88°，不是 DOF/(2 sin36.88°)）
            结论：斜视下仅视场中心窄带清晰，实际须用 Scheimpflug 倾斜相机
                  或 Z 轴扫描拼接（与 KSV NIMA MicroBAM 官方说明一致）。

对准        筒镜 f=200 mm，Δθ → 反射光偏 2Δθ → 光斑偏移 f·2Δθ
            Δθ=0.01° → 0.0698 mm（远小于像方靶面半宽 5.630 mm）
            Δθ=2.0°  → 13.9626 mm（超出视场）
            测角台 Newport URS50BPP 分辨率 0.0014° 足以把对准误差控制在 0.01° 内。

探测器      Basler acA2040-90um：满阱 11900 e⁻、暗噪声 13.8 e⁻、QE 62.07%
            基准信号取 0.67×满阱 = 7973 e⁻（10 ms 曝光）；SNR=88.2
            曝光降到 1 ms → 信号 797 e⁻，SNR=25.4
