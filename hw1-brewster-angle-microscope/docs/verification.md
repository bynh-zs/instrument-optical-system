## 检查口径说明

- **B 结构**：按装置示意图器件链逐项点名核对（光源 / HWP / GL / 样品槽-液相-单分子膜-滑障 / Obj / Apo / 探测器 / 法线 / θB / n1 n2 / 公式框）。
- **C 参数**：θB 由 `tanθB = n2/n1` 反算比对，确认不是人工指定的角度；器件型号已按选型逐件联网核实并回填，另登记建模基准 n2=1.333 与实测 n2=1.332106@632.8 nm/20 °C 的双口径及 θB 差值。
- **D 几何**：入射角 = 反射角 = θB、两者共面且关于法线对称、p 偏振电场在入射面内且垂直于传播方向、6 个光学器件落在光轴上且光轴沿光束方向、两束光端点落在液面原点。
- **E 属性**：关键对象均写入 `器件名称 / 器件类型 / 功能说明`，6 个主器件另含 `型号规格 / 工作波长 / 位置 / 光轴方向 / 尺寸 / 选型状态 / 核实来源 / 阶段状态`。
- **F 资源**：材质、灯光、2 台相机、渲染设置、内嵌参数表与建模脚本；另核三项可复现条件——中文字体已 pack 进文件（换机/换目录不掉字）、无未打包的外部图像、内嵌脚本与仓库内 `src/bam_build_scene.py` 逐字一致。侧视渲染时临时隐藏的机械支撑在最终保存时已全部恢复可见。
- **G 可渲染**：从磁盘重新打开后实际渲染一帧，确认文件未损坏、无缺失资源。

**检查边界（避免误读为「全部物理正确」）**：

1. B 结构、C 参数、E 属性三类，多数是「读取文件自身记录的属性/参数，再与设计值比对」，属**一致性校验**；它们能证明文件内部无矛盾、无遗漏，也能证明型号确为厂商公开的真实型号，但不能替代选型论证与物理仿真结果。
2. D 几何由对象坐标与方向向量**独立反算**（不依赖对象属性里的自述值），属几何独立校验。
3. G 只证明**本机**可渲染；换机可复现主要依靠 F 类的字体打包与无外部依赖两项保障。

## 仍需关注（不属于文件错误）

1. 器件型号与指标已逐件联网核实（见 `docs/verified-parts.md`），但选型论证、指标推导与对比见 `docs/system-design.md`；`.blend` 中的几何为按装置示意建立的模型，尺寸不按实物 1:1。
2. 图 1 的 `GL` 已由 BAM 文献确认还原为 Glan-Laser 方解石偏振棱镜（Thorlabs GL10-A）；`Apo` 仍属**推断**，按无限远校正光路的筒镜（Nikon MXA22018）还原，待文献确认。
3. `反射光束` 在物理上代表**膜区/微观结构引起的微弱反射信号**；纯水界面 p 偏振在 θB 下反射率≈0，图中红线为示意，不是裸界面反射（该说明已写入反射光束对象属性）。
4. 「除样品外影响反射光强的其他因素」「光路对准 / 图像对焦」与因素对测量结果的影响，见 `docs/measurement-factors.md` 与 `src/bam_model.py` 生成的扫描数据。
5. 两张预览图分工不同：侧视正交图带全部标注、与装置示意图对应；立体图在渲染时临时隐藏文字与公式白板，只展示三维搭建关系（立柱与标注同轴，透视下必然互相穿插）。`.blend` 内文字对象全部保留且可渲染。
