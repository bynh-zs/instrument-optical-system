# 题目与设计约束（布儒斯特角显微镜 BAM）

> 来源：课程大作业《布儒斯特角显微镜》题目页（1 页，含 1 张装置示意图）与课程通用提交要求。
> 本文件只登记**与设计直接相关**的约束；报告的排版模板（封面字段、四章结构、字体字号）属于课程事务，不在本库复述。

## 一、题目

布儒斯特角显微镜（Brewster Angle Microscope, BAM）利用布儒斯特角原理观测**薄膜表面特性与微观结构**，主要用于**表面与界面研究**，在单分子膜、液晶、聚合物等领域应用广泛。

物理基础：p 偏振（TM）光以布儒斯特角 θB 入射到空气/水界面时，理想平整界面的反射率为零；界面被单分子膜覆盖后，膜层的折射率与厚度破坏零反射条件，反射光重新出现，其强度与膜层光学厚度相关。把这束微弱反射光成像，就得到膜区与裸水区的亮度对比，即膜的畴结构。

## 三、装置示意图隐含的设计约束

按光路先后，器件链为：

```
光源 → HWP（半波片）→ GL（起偏棱镜）→ 样品液面 → Obj（物镜）→ Apo（筒镜）→ 探测器
```

图注只写 `GL`、`Apo` 两个缩写。按 BAM 一手文献，`GL` 可还原为 Glan-Laser 方解石起偏棱镜（Thorlabs GL10-A 是常用件，有直接文献支撑）；`Apo` 按无限远校正光路还原为筒镜/复消色差镜组（Nikon MXA22018），属**推断**，需在文档中注明。核对记录见 [verified-parts.md](verified-parts.md)。

几何约束：

1. **入射角由折射率决定**：`tanθB = n2/n1`，不得人工指定。空气/水界面 θB = arctan(1.333) = 53.123°。
2. **入射、法线、反射共面且对称**：入射角 = 反射角 = θB，入射面为 XZ 平面。
3. **折射率分区是设计变量**：界面上方 n1（气相），下方 n2（液相），两者都要标注。
4. **θB 标在反射侧**：示意图把 θB 圆弧画在法线右侧，等价但需与图一致。

偏振与样品约束：

5. **p 偏振 + 双偏振元件串联**：图中 HWP 与 GL 并存，意图是先用 GL 把消光比拉到 1×10⁵，再用 HWP **无损旋转**偏振面——调偏振时不转动激光器，不破坏光路准直。
6. **样品是 Langmuir 膜**：液面上有亲水头基（红点）与疏水链，左侧有滑障，标注 `π(A)` 或 `π(t)` 与 `ΔA`。这意味着探测器要有足够帧率，槽体必须与光路固连。
7. **反射光束是膜区信号**：裸水界面 p 偏振在 θB 下反射率≈0，图中画出的反射光应理解为膜区/微观结构引起的微弱反射，不是裸界面反射。
8. **探测器是面阵器件**：蓝色方框内白色圆形靶面，即 CCD/CMOS。
