# 光条中心提取：射影先验 + 灰度重心

互反射会在同一列造出多个亮度峰，若直接取全局极大，会把副峰（假光条）当主光条。本算法不改成像，只在图像处理层面用**多线系统的结构先验**剔峰。

## 1. 流程

| 步 | 名称 | 做法 |
|---|---|---|
| S1 | ROI 选取 | 按行亮度均值取 70% 分位以上行段，屏蔽台面与背景 |
| S2 | 背景归一化 | 逐列减去行带亮度中值，压掉环境照明与台面反光的缓变分量 |
| S3 | 候选峰检测 | 沿列方向取局部极大 + 18% 阈值，得到"主光条 + 副光条"候选 |
| S4 | 结构先验选线 | 用一维射影模型拟合候选组合，残差 + 强度项联合代价最小的一组判为主光条 |
| S5 | 亚像素定位 | 保留峰 ±9 px 邻域内做加权灰度重心，抗饱和与噪声 |
| S6 | 输出 | 中心列坐标、按已知线距自标定比例尺、射影残差与间距统计 |

## 2. 为什么用射影模型而不是"等间距"

相机斜视时，物方等距的 7 条光平面在像面上并不等距（近端压缩、远端拉伸）。设第 i 条光条中心为 u_i，一维射影（交比）模型为

    u_i = (a·i + b) / (c·i + 1)

它正是共线点列在透视投影下的像，能吸收压缩；`c = 0` 时退化为等间距。求解时把方程整理为线性形式 `a·i + b − u·c·i − u = 0`，用最小二乘一次解出三个参数。

对比：等间距先验对同一帧给出 CV 6.96%（172.46—212.07 px），而射影模型残差 RMS 仅 1.11 px（≈1.44 mm，相对 250 mm 线距 0.57%）。

## 3. 结果（data/groove_render.png，1600×1200）

- ROI：339—865 行；候选峰 9；检出 7/7；剔除副峰 2；
- 中心列坐标（px）：214.55, 387.01, 568.80, 760.32, 957.27, 1162.94, 1375.01；
- 相邻间距（px）：172.46, 181.79, 191.52, 196.95, 205.67, 212.07；平均 193.41 px；
- 自标定比例尺 1.2926 mm/px（按设计线距 250 mm）；
- 射影拟合 a = 167.6203、b = 213.3144、c = −0.019018，残差 RMS = 1.11 px。

运行 `python src/line_center_extract.py` 会重新生成叠加图、列亮度曲线与 `out/stats.txt`，数值应与之逐项一致。

## 4. 适用边界

- 只依赖两个前提：线数与线距已知、被测件与背景在灰度上可分离；
- 不依赖槽型、槽深或材质，对 V 槽、梯形槽、台阶等任何产生多弹射的结构同样适用；
- 当前比例尺由设计线距自标定，属"相对尺度"；实机应改用标定所得的光平面与相机内参，把候选峰反投影为射线求交，可同时消除透视失配并保证绝对尺度。
