# Blender 仿真说明

用 Blender 5.2 LTS 的 Cycles 路径追踪复现"多线结构光成像 + 沟槽互反射"，两个场景共用同一测头与光学参数：

- `01_材质对比`：三块 2.4×0.5×0.06 m 试板，哑光 / 高反光 / 透明，用于任务②；
- `02_沟槽互反射`：V60°、V90°、梯形槽三件沟槽件，用于任务③及算法测试。

## 1. 渲染设置（两场景一致）

| 项 | 值 |
|---|---|
| 引擎 | Cycles，GPU（无独显则 CPU） |
| 采样 / 降噪 | 128 / OpenImageDenoise |
| 分辨率 | 1600×1200，100% |
| 色彩管理 | AgX，Look None，曝光 0，Gamma 1.0 |
| 帧率 / 帧范围 | 24 fps，1—96 |
| 输出 | PNG RGBA |

## 2. 关键对象的参数

### 2.1 七条线光源（`线光源_±0.75 … 线光源_+0.75`）

Blender 的"线"类型光源是零宽度一维光源，没有出光尺寸也无法设发散角，照出的光条没有宽度。因此改用**极窄矩形面光源**：

- 类型 AREA / RECTANGLE，尺寸 0.012 × 1.55 m，`spread` 0.004 rad（约 0.23°），能量 9 W，颜色 (1.0, 0.08, 0.03)；
- 父级 `测头_原点`，位置 (dx, 0, 3.55)，dx = −0.75 … +0.75，步距 0.25 m；
- 3.5 m 投射距离上的线宽 ≈ 12 mm + 0.004 rad × 3.5 m ≈ 26 mm。

> 注意：9 W 是渲染能量单位，不是激光器的光学功率，不能当作"9 瓦激光"。

### 2.2 相机（`T4_相机_12mm`）

- 位置 (0.75, 0, 2.895)，旋转 (0, 14.52°, 0)；
- 焦距 10 mm、传感器宽 7.2 mm、适配方式"水平"、裁剪 0.02—50 m；
- 对象名沿用了早期的"12 mm"，实际是 10 mm：12 mm 时纵向只覆盖约 1.32 m，装不下 1.5 m 的试板带。

### 2.3 材质（编号 01—13，06 为空号）

| 材质 | 基色（线性 RGB） | 金属度 | 粗糙度 | 其他 |
|---|---|---|---|---|
| 07_哑光灰 | 0.58, 0.58, 0.60 | 0 | 1.00 | — |
| 08_高反光 | 0.92, 0.92, 0.94 | 1.0 | 0.08 | — |
| 09_透明玻璃 | 0.98, 0.99, 1.00 | 0 | 0.06 | Transmission 1.0、IOR 1.517 |
| 11_沟槽件 | 0.55, 0.55, 0.58 | 1.0 | 0.18 | — |

颜色用**线性 RGB 数值**输入，不要用十六进制（0.58 线性约合 #C8C8CA，直接按 58% 填会偏暗一档）。

### 2.4 沟槽件

- 外形 0.85 × 0.62 × 0.22 m，沿 x 位于 −0.9 / 0 / +0.9 m，**绕 Z 轴转 90°**——槽长向必须与光条垂直，否则光条只落在同一侧壁，不会产生多弹射；
- V60°：槽口 0.10 m、半宽 0.05 m、开口角 60°、槽深 0.087 m、槽距 0.13 m；
- V90°：开口角 90°、槽深 0.05 m、槽距 0.13 m；
- 梯形槽：平底 0.05 m、槽深 0.04 m、槽距 0.15 m。

## 3. 踩过的坑（照做可省几小时）

1. **光片对象**：`光片_*` 是 Emission 强度 300 的发光面片，`hide_render=True`，只用于视口展示光条位置；若误让它们参与渲染，整块试板会被红光淹没、细光条被糊掉。视口预览里它们默认可见，所以"视口看得见、F12 渲出来不一样"是正常现象。
2. **扩散角**：`spread` 保持 0.004 rad。默认 180° 会让试板整片发红、看不到光条。
3. **相机倾角**：14.52° 是设计必需，不是建模失误；改成铅垂向下会让试板左半出画。
4. **采样口径**：面板里"采样 → 视图"的 1024 是视口预览采样，成片用"渲染"的 128。
5. **动画**：只在 `测头_原点` 上打关键帧（帧 1/48/96 的 x = −0.40/0/+0.40），相机与 7 条光源靠父子关系跟随，等效刚性扫描。
6. **颜色管理**：AgX + 曝光 0；若留在 Standard，光条会发白一片、失去层次。

## 4. 复现命令

```bash
# 审计场景参数（不渲染，秒级）
blender -b assets/multi_line_scene.blend --python tools/blender_audit.py

# 渲染场景 02 的第 48 帧（与仓库示例图一致）
blender -b assets/multi_line_scene.blend --python tools/render_camera.py -- \
    --scene 02_沟槽互反射 --cam T4_相机_12mm --frames 48 --samples 128 \
    --res 1600x1200 --out out/reflection.png
```
